## 01 · 排序算法

### 0. 排序算法总览

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 |
|------|:-------------:|:-------------:|:---------:|:-----:|
| 冒泡排序 | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| 选择排序 | O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| 插入排序 | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| 希尔排序 | O(n log n)~O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | ❌ 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | ✅ 稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | ❌ 不稳定 |
| 基数排序 | O(n×k) | O(n×k) | O(n+k) | ✅ 稳定 |
| 桶排序 | O(n+k) | O(n²) | O(n+k) | ✅ 稳定 |

### 1. 冒泡排序（Bubble Sort）

**概念：** 重复遍历数组，依次比较相邻两个元素，如果顺序错误就交换。每轮遍历将最大（或最小）的元素"冒泡"到数组末尾。

- **本质：** 相邻元素两两比较，大的往后沉
- **优化：** 设置 `flag`，如果某一轮没有发生交换，说明已有序，提前终止
- **时间复杂度：** 最好 O(n)，最坏 O(n²)

```c
void bubble_sort(int a[], int n) {
    int i, j, t, flag;
    for (i = 0; i < n - 1; i++) {
        flag = 0;
        for (j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                flag = 1;
            }
        }
        if (!flag) break;   // 没有交换，提前结束
    }
}
```

**优化要点：** `flag` 变量是关键优化 — 如果某一轮没有任何交换，说明数组已经完全有序，直接跳出循环（最好情况 O(n)）。

### 2. 选择排序（Selection Sort）

**概念：** 每次从未排序部分找到最小元素，放到已排序部分的末尾。每一轮确定一个元素的最终位置。

- **本质：** 每轮选择最小值放到前面
- **特点：** 交换次数少（最多 n-1 次），但比较次数固定为 n(n-1)/2
- **不稳定原因：** 交换可能破坏相等元素的相对顺序

```c
void selection_sort(int a[], int n) {
    int i, j, min, d, temp;
    for (i = 0; i < n - 1; i++) {
        min = a[i];
        d = i;
        for (j = i + 1; j < n; j++) {
            if (a[j] < min) {
                min = a[j];
                d = j;
            }
        }
        if (d != i) {
            temp = a[i];
            a[i] = a[d];
            a[d] = temp;
        }
    }
}
```

### 3. 插入排序（Insertion Sort）

**概念：** 将数组分为已排序和未排序两部分，每次从未排序部分取一个元素，插入到已排序部分的正确位置。

- **本质：** 类似打扑克牌时整理手牌
- **适用场景：** 数据量小或基本有序的数组
- **插入方式：** 元素后移腾出位置（不是交换）

```c
void insertion_sort(int a[], int n) {
    int i, j, t;
    for (i = 1; i < n; i++) {
        t = a[i];
        for (j = i; j > 0 && a[j - 1] > t; j--) {
            a[j] = a[j - 1];
        }
        a[j] = t;
    }
}
```

**插入 vs 交换：** 插入排序用"元素后移"代替"两两交换"，减少了赋值操作次数。

### 4. 希尔排序（Shell Sort）

**概念：** 插入排序的改进版。先将数组按一定增量 d 分组，对每组进行插入排序，然后逐步缩小 d，直到 d=1 时做最后一次插入排序。

- **本质：** 分组插入排序，让大元素快速移动到后面
- **增量序列：** 通常取 n/2, n/4, ..., 1（也叫缩小增量排序）
- **优势：** 突破了 O(n²) 的瓶颈，最坏可达到 O(n²)，平均约 O(n^1.3)

```c
void shell_sort(int a[], int n) {
    int i, j, d, t;
    for (d = n / 2; d > 0; d /= 2) {
        for (i = d; i < n; i++) {
            t = a[i];
            for (j = i; j >= d && a[j - d] > t; j -= d) {
                a[j] = a[j - d];
            }
            a[j] = t;
        }
    }
}
```

### 5. 快速排序（Quick Sort）

**概念：** 选一个基准（pivot），将数组分成两部分：左边都比 pivot 小，右边都比 pivot 大，然后递归地对左右两部分排序。

- **本质：** 分治思想 + 分区操作
- **核心：** Partition（分区）函数
- **Pivot 选择：** 通常取第一个元素、最后一个元素或随机选
- **最坏情况：** 数组已经有序时退化为 O(n²)

```c
int Position(int *a, int left, int right) {
    int pivot = a[left];
    int i = left;
    int j = right;
    while (i < j) {
        while (i < j && a[j] > pivot) j--;
        if (i < j) {
            a[i] = a[j];
            i++;
        }
        while (i < j && a[i] <= pivot) i++;
        if (i < j) {
            a[j] = a[i];
            j--;
        }
    }
    a[i] = pivot;
    return i;
}

void quick_sort(int *a, int left, int right) {
    if (left < right) {
        int pi = Position(a, left, right);
        quick_sort(a, left, pi - 1);
        quick_sort(a, pi + 1, right);
    }
}
```

**挖坑法图解：** 取 a[left] 为 pivot，相当于挖了一个坑。从右边找比 pivot 小的填坑，左边就多一个坑；再从左边找比 pivot 大的填右边的坑，以此类推。最后把 pivot 填回最终的坑。

### 6. 归并排序（Merge Sort）

**概念：** 将数组递归地分成两半，分别排序，然后合并两个有序子数组。

- **本质：** 分治 + 合并
- **关键操作：** Merge（合并）两个已排序的数组
- **空间开销：** 需要 O(n) 的辅助空间
- **稳定排序：** 合并时相等元素左半优先，保持稳定性

```c
void merge_sort(int a[], int left, int mid, int right) {
    int i = 0, j = 0, k = left;
    int nL = mid - left + 1;
    int nR = right - mid;
    int *L = (int*)malloc(nL * sizeof(int));
    int *R = (int*)malloc(sizeof(int) * nR);

    // 复制到临时数组
    while (i < nL) L[i++] = a[k++];
    while (j < nR) R[j++] = a[k++];

    i = 0; j = 0; k = left;
    // 合并：谁小谁先放入
    while (i < nL && j < nR) {
        if (L[i] < R[j]) a[k++] = L[i++];
        else a[k++] = R[j++];
    }
    // 处理剩余元素
    while (i < nL) a[k++] = L[i++];
    while (j < nR) a[k++] = R[j++];

    free(L);
    free(R);
}

void mergesortRecursive(int a[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        mergesortRecursive(a, left, mid);
        mergesortRecursive(a, mid + 1, right);
        merge_sort(a, left, mid, right);
    }
}
```

**递归过程：** 先不断二分到单元素（天然有序），再两两合并、四四合并……直到整个数组有序。

### 7. 堆排序（Heap Sort）

**概念：** 利用最大堆（或最小堆）进行排序。先将数组构建成最大堆，然后反复取出堆顶（最大值）放到数组末尾。

- **本质：** 堆（完全二叉树）→ 最大堆 → 不断取堆顶
- **Heapify（堆化）：** 调整以 i 为根的子树，使其满足堆性质
- **建堆：** 从最后一个非叶子节点（n/2-1）开始往前做 Heapify

```c
void Heapify(int a[], int n, int i) {
    int largest = i;
    int left = i * 2 + 1;
    int right = i * 2 + 2;
    int temp;
    if (left < n && a[left] > a[largest]) largest = left;
    if (right < n && a[right] > a[largest]) largest = right;
    if (largest != i) {
        temp = a[i];
        a[i] = a[largest];
        a[largest] = temp;
        Heapify(a, n, largest);
    }
}

void Heapsort(int a[], int n) {
    int i, temp;
    // 建堆
    for (i = n / 2 - 1; i >= 0; i--) {
        Heapify(a, n, i);
    }
    // 排序
    for (i = n - 1; i > 0; i--) {
        temp = a[0];
        a[0] = a[i];
        a[i] = temp;
        Heapify(a, i, 0);
    }
}
```

**堆排序过程：**
1. 建堆：从 n/2-1 到 0，依次 Heapify
2. 排序：将堆顶（最大值）与末尾交换，堆大小减 1，重新 Heapify

### 8. 基数排序（Radix Sort）

**概念：** 按位数（个位、十位、百位……）依次排序。使用"桶"来分配元素，从最低有效位开始到最高有效位。

- **本质：** 多关键字排序，按位分配+收集
- **适用场景：** 数据范围比较小且非负整数
- **k 的含义：** 最大数字的位数

```c
void radixsort(int *a, int n) {
    int max = a[0], i, j;
    for (i = 1; i < n; i++) {
        if (a[i] > max) max = a[i];
    }

    int exp, j;
    for (exp = 1; (max / exp) > 0; exp *= 10) {
        int bucket[10][n];
        int bucketsize[10] = {0};
        for (i = 0; i < n; i++) {
            int index = (a[i] / exp) % 10;
            bucket[index][bucketsize[index]++] = a[i];
        }
        int index = 0;
        for (i = 0; i < 10; i++) {
            for (j = 0; j < bucketsize[i]; j++) {
                a[index++] = bucket[i][j];
            }
        }
    }
}
```

### 9. 桶排序（Bucket Sort）

**概念：** 将元素按范围分配到不同的桶中，每个桶内部再排序（通常用插入排序），然后按桶顺序收集。

- **适用场景：** 数据均匀分布时效率最高
- **桶内排序：** 通常用插入排序或递归用桶排序
- **空间换时间：** 桶的数量越多，效率越高但空间开销越大

```c
void bucketSort4Digit(int arr[], int n) {
    int i, j, b;
    int max = arr[0];
    for (i = 1; i < n; i++) {
        if (arr[i] > max) max = arr[i];
    }
    int bucketCount = max / 1000 + 1;
    if (bucketCount > 10) bucketCount = 10;

    int** buckets = (int**)malloc(bucketCount * sizeof(int*));
    int* bucketSizes = (int*)calloc(bucketCount, sizeof(int));
    for (i = 0; i < bucketCount; i++) {
        buckets[i] = (int*)malloc(n * sizeof(int));
    }
    for (i = 0; i < n; i++) {
        int bucketIndex = arr[i] / 1000;
        if (bucketIndex >= bucketCount) bucketIndex = bucketCount - 1;
        buckets[bucketIndex][bucketSizes[bucketIndex]++] = arr[i];
    }
    // 每个桶内插入排序
    for (b = 0; b < bucketCount; b++) {
        for (i = 1; i < bucketSizes[b]; i++) {
            int key = buckets[b][i];
            for (j = i - 1; j >= 0 && buckets[b][j] > key; j--) {
                buckets[b][j + 1] = buckets[b][j];
            }
            buckets[b][j + 1] = key;
        }
    }
    // 收集
    int index = 0;
    for (b = 0; b < bucketCount; b++) {
        for (j = 0; j < bucketSizes[b]; j++) {
            arr[index++] = buckets[b][j];
        }
    }
    // 释放内存
    for (i = 0; i < bucketCount; i++) free(buckets[i]);
    free(buckets);
    free(bucketSizes);
}
```

### 10. 计数排序（Counting Sort）

**概念：** 计数排序不是基于比较的排序，而是统计每个元素出现的次数，再根据计数把元素放回正确位置。适用于数据范围小（max 不大）且为整数的情况。

- **本质：** 用额外数组统计频率，空间换时间
- **时间复杂度：** O(n + k)，k 为数据范围（max 值）
- **空间复杂度：** O(k)
- **稳定性：** 稳定

```c
void counting_sort(int a[], int n, int max) {
    int *count = (int*)calloc(max + 1, sizeof(int));
    for (int i = 0; i < n; i++) {
        count[a[i]]++;                  // 统计每个值的出现次数
    }
    int index = 0;
    for (int v = 0; v <= max; v++) {
        while (count[v] > 0) {          // 按值从小到大收集
            a[index++] = v;
            count[v]--;
        }
    }
    free(count);
}
```

**适用：** 数据范围小（如成绩 0-100、年龄）时非常快，可达 O(n)。

### 11. 排序算法综合对比

| 排序 | 平均 | 最坏 | 空间 | 稳定 | 适用场景 |
|------|------|------|------|------|---------|
| 冒泡 | O(n²) | O(n²) | O(1) | ✅ | 小数据、教学 |
| 选择 | O(n²) | O(n²) | O(1) | ❌ | 交换次数最少的场景 |
| 插入 | O(n²) | O(n²) | O(1) | ✅ | 数据基本有序、小数据 |
| 希尔 | O(n^1.3) | O(n²) | O(1) | ❌ | 中等数据 |
| 快排 | O(n log n) | O(n²) | O(log n) | ❌ | 通用首选 |
| 归并 | O(n log n) | O(n log n) | O(n) | ✅ | 大数据、要求稳定 |
| 堆排 | O(n log n) | O(n log n) | O(1) | ❌ | 不能使用额外空间 |
| 计数 | O(n+k) | O(n+k) | O(k) | ✅ | 整数且范围小 |
| 基数 | O(n×k) | O(n×k) | O(n+k) | ✅ | 多位整数 |
| 桶 | O(n+k) | O(n²) | O(n+k) | ✅ | 数据均匀分布 |

**如何选择排序算法：**
- 数据量小 → 插入排序（简单高效）
- 数据基本有序 → 插入排序（接近 O(n)）
- 通用排序 → 快速排序（平均最快）
- 要求稳定 + 大数据 → 归并排序
- 内存紧张 → 堆排序（O(1) 空间）
- 整数且范围小 → 计数/基数/桶排序

## 02 · 链表（Linked List）

### 1. 链表基本概念

**概念：** 链表是一种动态数据结构，由一系列节点（Node）组成，每个节点包含数据域和指向下一个节点的指针（`next`）。

- **与数组对比：** 数组连续存储、随机访问 O(1)；链表离散存储、顺序访问 O(n)
- **类型：** 单链表、双向链表、循环链表
- **优点：** 插入/删除快（O(1)，已知位置），动态大小
- **缺点：** 不支持随机访问，需要额外指针空间

### 2. 链表的节点定义

```c
typedef int datatype;

typedef struct node {
    datatype data;          // 数据域
    struct node *next;      // 指针域，指向下一个节点
} Node;
```

**链表常用指针：**
- `first` / `head`：头指针，指向第一个节点
- `tail`：尾指针，指向最后一个节点（用尾插法时使用）
- `p`：遍历指针

### 3. 头插法（创建链表）

**概念：** 新节点始终插入到链表头部，新节点变为新的第一个节点。输入顺序和链表顺序相反。

- **本质：** 每次新节点指向当前头节点，然后更新头指针为新节点
- **结果：** 输入 1→2→3，链表为 3→2→1（逆序）

```c
Node* Createlist_head() {
    Node *p = NULL, *first = NULL;
    datatype data;
    printf("Input data, end with -1:");
    scanf("%d", &data);
    while (data != -1) {
        p = (Node*)malloc(sizeof(Node));   // 创建新节点
        p->data = data;
        p->next = first;                    // 新节点指向原头节点
        first = p;                          // 更新头指针
        scanf("%d", &data);
    }
    return first;
}
```

### 4. 尾插法（创建链表）

**概念：** 新节点始终插入到链表尾部，需要一个 `tail` 指针跟踪尾节点。输入顺序和链表顺序一致。

- **本质：** 新节点插入到 `tail->next`，然后更新 `tail` 为新节点
- **第一个节点的特殊处理：** 第一个节点既要设置 `first` 也要设置 `tail`

```c
Node* Createlist_tail() {
    Node *p = NULL, *tail = NULL, *first = NULL;
    datatype data;
    int n = 0;
    printf("Input data, end with -1:");
    scanf("%d", &data);
    while (data != -1) {
        p = (Node*)malloc(sizeof(Node));
        p->data = data;
        p->next = NULL;
        if (n == 0) {           // 第一个节点
            first = p;          // 头指针指向第一个节点
        } else {
            tail->next = p;     // 原尾节点指向新节点
        }
        tail = p;               // 更新尾指针
        n++;
        scanf("%d", &data);
    }
    return first;
}
```

### 5. 链表遍历（Display）

**概念：** 从 `first` 开始，利用 `p = p->next` 依次访问每个节点，直到 `p == NULL`。

```c
void Display(Node *first) {
    Node *p = first;            // 遍历指针，从头开始
    while (p) {
        printf("%p %d %p\n", p, p->data, p->next);
        p = p->next;            // 指向下一个节点
    }
}
```

### 6. 链表查找（Search）

**概念：** 遍历链表，逐个比较节点的数据域，找到返回 1，找不到返回 0。

```c
int Search(Node *first, datatype x) {
    Node *p = first;
    while (p) {
        if (p->data == x) {
            printf("%p %d\n", p, p->data);
            return 1;           // 查找成功
        }
        p = p->next;
    }
    return 0;                   // 查找失败
}
```

### 7. 链表删除节点（Delete）

**概念：** 删除第 i 个节点。需要找到第 i-1 个节点（前驱），将其 `next` 指向第 i+1 个节点，然后释放第 i 个节点。

- **删除头节点：** 特殊处理，直接 `first = first->next`
- **删除中间/尾节点：** 前驱节点的 `next` 指向被删节点的 `next`
- **必须 free：** 释放被删节点的内存，防止内存泄漏

```c
Node* Delete(Node *first, int i) {
    Node *p, *pre;      // p 指向节点 i，pre 指向 i-1
    int j = 1;
    p = pre = first;

    if (first == NULL) return NULL;     // 空链表
    if (i == 1) {                       // 删除头节点
        first = first->next;
        free(p);
    } else if (i > 1) {
        while (pre->next && j < i - 1) { // 找到第 i-1 个节点
            pre = pre->next;
            j++;
        }
        if (pre->next) {                // 节点存在
            p = pre->next;
            pre->next = p->next;
            free(p);
        } else {
            printf("error\n");
        }
    }
    return first;
}
```

### 8. 链表封装成 List 结构体

**概念：** 把头指针封装到结构体 `List` 中，方便传递和管理。

```c
typedef struct list {
    Node *head;
} List;

// 尾插法
void add(List *plist, int number) {
    Node *p = (Node*)malloc(sizeof(Node));
    p->value = number;
    p->next = NULL;
    if (plist->head == NULL) {
        plist->head = p;
    } else {
        Node *last = plist->head;
        while (last->next) {
            last = last->next;
        }
            last->next = p;
    }
}
```

### 9. 链表综合操作（单链表1.c）

**包含功能的完整实现：** 尾插创建 + 遍历打印 + 查找 + 删除指定值节点。

```c
// 删除指定值的节点（而非第i个）
for (p = NULL, q = list.head; q; p = q, q = q->next) {
    if (q->data == number) {
        if (p) {
            p->next = q->next;      // 删除中间节点
        } else {
            list.head = q->next;    // 删除头节点
        }
        free(q);
        break;
    }
}
```

**双指针技巧：** p 指向当前节点的前驱，q 指向当前节点。初始化 `p = NULL, q = head`，遍历时交替前进：`p = q, q = q->next`。这样找到目标节点时，p 就是前驱，可以直接操作。

### 10. 单链表逆转

**概念：** 将链表的指针方向反转，使尾变头、头变尾。每轮迭代将当前节点的 `next` 指向前一个节点。

```c
Ptr Reverse(Ptr head, int K) {
    cnt = 1;
    new = head->next;
    old = new->next;
    while (cnt < K) {
        tmp = old->next;
        old->next = new;
        new = old;
        old = tmp;
        cnt++;
    }
    head->next->next = old;
    return new;
}
```

### 11. 双向链表

**概念：** 双向链表的每个节点有两个指针，`prev` 指向前驱，`next` 指向后继。可以从两个方向遍历，已知节点可直接删除 O(1)。

- **优点：** 支持双向遍历；删除已知节点 O(1)（不需要额外找前驱）
- **缺点：** 每个节点多一个指针，空间开销更大

```c
typedef struct DNode {
    int data;
    struct DNode *prev, *next;      // 前驱和后继指针
} DNode;

// 在节点 p 之后插入新节点 s
void InsertAfter(DNode *p, DNode *s) {
    s->prev = p;
    s->next = p->next;
    if (p->next) p->next->prev = s; // 更新原后继的前驱
    p->next = s;
}

// 删除节点 p（无需前驱指针，直接通过 prev 回指）
void DeleteDNode(DNode *p) {
    if (p->prev) p->prev->next = p->next;   // 前驱指向后继
    if (p->next) p->next->prev = p->prev;   // 后继指向前驱
    free(p);
}
```

### 12. 循环链表

**概念：** 循环链表的最后一个节点的 `next` 指向头节点（或第一个节点），形成一个环。从任意节点出发都能遍历整个链表。

- **类型：** 单向循环链表、双向循环链表
- **特点：** 常用尾指针代替头指针，找表头/表尾都 O(1)
- **应用：** 约瑟夫环、操作系统进程调度

**约瑟夫环（Josephus）问题：** n 个人围成一圈，从第 k 个开始报数，报到 m 的人出列，直到全部出列，求输出顺序。

```c
// 约瑟夫环：循环链表实现
void Josephus(int n, int m) {
    // 构建 1..n 的循环链表
    Node *head = NULL, *tail = NULL;
    for (int i = 1; i <= n; i++) {
        Node *p = (Node*)malloc(sizeof(Node));
        p->data = i;
        if (head == NULL) { head = tail = p; }
        else { tail->next = p; tail = p; }
    }
    tail->next = head;              // 首尾相连成环

    Node *p = tail;                 // 从尾开始，便于删除头节点
    while (p->next != p) {
        for (int i = 1; i < m; i++) p = p->next;   // 走 m-1 步
        Node *del = p->next;                        // 第 m 个出列
        p->next = del->next;
        printf("%d ", del->data);
        free(del);
    }
    printf("%d\n", p->data);        // 最后一个
}
```

**单链表 vs 双向链表 vs 循环链表：**

| 类型 | 遍历方向 | 删除已知节点 | 找表尾 | 应用 |
|------|---------|-------------|--------|------|
| 单链表 | 仅向后 | O(n) | O(n) | 基础链表 |
| 双向链表 | 前后均可 | O(1) | O(n) | 需要反向遍历 |
| 循环链表 | 可绕环 | O(n) | O(1)（尾指针） | 约瑟夫环、调度 |

## 03 · 栈（Stack）

### 1. 栈的基本概念

**概念：** 栈是一种限制只在表的一端进行插入和删除操作的线性表。允许操作的一端称为栈顶（top），另一端称为栈底。简称 LIFO（后进先出，Last In First Out）。

- **核心操作：** `Push（入栈）`、`Pop（出栈）`、`Peek/Top（查看栈顶）`
- **生活类比：** 一叠盘子——后放的先取
- **应用场景：** 函数调用栈、表达式求值、括号匹配、撤销操作

### 2. 顺序栈（数组实现）

**概念：** 使用数组存储栈元素，`top` 指针指向栈顶元素的位置（-1 表示空栈）。

```c
#define maxsize 10

typedef struct Stack {
    int data[maxsize];
    int top;
} Stack;

void initStack(Stack *s) {
    s->top = -1;        // -1 表示空栈
}

void Push(Stack *s, int value) {
    if (s->top < maxsize - 1) {
        s->data[++(s->top)] = value;    // 先移指针，再存数据
    } else {
        printf("stack is full\n");
    }
}

int Pop(Stack *s) {
    if (s->top > -1) {
        return s->data[(s->top)--];     // 先取数据，再移指针
    } else {
        printf("stack is empty\n");
        return 0;
    }
}

int Peek(Stack *s) {
    if (s->top >= 0) {
        return s->data[s->top];
    }
    return 0;
}

bool IsEmpty(Stack *s) {
    return s->top == -1;
}

int size(Stack *s) {
    return s->top + 1;
}
```

**栈的扩展操作：**
- `reverseStack`：反转栈（借助辅助栈）
- `copyStack`：复制栈
- `mergeStack`：合并两个栈
- `Search`：查找元素位置（从栈顶算起）
- `Swap`：交换栈顶两个元素
- `modifyTop`：修改栈顶值

```c
// 反转栈
void reverseStack(Stack *s) {
    if (IsEmpty(s)) return;
    Stack *temp = (Stack*)malloc(sizeof(Stack));
    initStack(temp);
    int i;
    for (i = s->top; i >= 0; i--) {
        temp->data[++(temp->top)] = s->data[i];
    }
    for (i = temp->top; i >= 0; i--) {
        printf("%d ", temp->data[i]);
    }
    printf("\n");
}

// 合并栈（s2 并入 s1）
void mergeStack(Stack *s1, Stack *s2) {
    Stack *t = (Stack*)malloc(sizeof(Stack));
    initStack(t);
    while (!IsEmpty(s2)) Push(t, Pop(s2));
    while (!IsEmpty(t)) Push(s1, Pop(t));
}
```

### 3. 链式栈（链表实现）

**概念：** 用链表实现栈，栈顶就是链表的头节点，入栈出栈都在头部操作（O(1)）。

```c
typedef struct StackNode {
    ElementType data;
    struct StackNode *next;
} StackNode;

typedef struct {
    StackNode *top;     // 栈顶指针
    int size;           // 栈大小
} LinkStack;

LinkStack* CreateLinkStack() {
    LinkStack *S = (LinkStack*)malloc(sizeof(LinkStack));
    S->top = NULL;
    S->size = 0;
    return S;
}

int LinkPush(LinkStack *S, ElementType item) {
    StackNode *newNode = (StackNode*)malloc(sizeof(StackNode));
    newNode->data = item;
    newNode->next = S->top;     // 新节点指向原栈顶
    S->top = newNode;           // 更新栈顶
    S->size++;
    return 1;
}

ElementType LinkPop(LinkStack *S) {
    if (S->top == NULL) return -1;
    StackNode *temp = S->top;
    ElementType item = temp->data;
    S->top = S->top->next;      // 栈顶下移
    free(temp);
    S->size--;
    return item;
}
```

**顺序栈 vs 链式栈：**

| 对比 | 顺序栈 | 链式栈 |
|------|--------|--------|
| 空间 | 固定大小，可能溢出 | 动态分配，不会溢出 |
| 访问速度 | 数组下标，O(1) | 指针操作，O(1) |
| 实现复杂度 | 简单 | 稍复杂（需 malloc/free） |

### 4. 双栈共享空间

**概念：** 两个栈共用同一个数组，一个从低地址向上增长（top1），一个从高地址向下增长（top2）。中间相遇时栈满。

- **空间利用：** 一个栈空时另一个栈可以用全部空间
- **判满条件：** `top2 - top1 == 1`

```c
typedef struct {
    ElementType data[MAXSIZE];
    int top1;       // 栈1栈顶（从低到高）
    int top2;       // 栈2栈顶（从高到低）
} DoubleStack;

DoubleStack* CreateDoubleStack() {
    DoubleStack *DS = (DoubleStack*)malloc(sizeof(DoubleStack));
    DS->top1 = -1;
    DS->top2 = MAXSIZE;     // 从数组末尾开始
    return DS;
}

int DoublePush(DoubleStack *DS, ElementType item, int stackNum) {
    if (DS->top2 - DS->top1 == 1) {
        printf("栈满\n");
        return 0;
    }
    if (stackNum == 1) {
        DS->data[++(DS->top1)] = item;
    } else if (stackNum == 2) {
        DS->data[--(DS->top2)] = item;
    }
    return 1;
}
```

### 5. 两个队列实现栈

**概念：** 使用两个队列模拟栈的 LIFO 特性。始终保持其中一个队列的队首是"栈顶"。

- **思路：** push 时把元素放到空队列 q2，然后把 q1 的所有元素移到 q2，最后交换 q1 和 q2。这样 q1 的队首就是最新入栈的元素。

```c
typedef struct {
    Queue *q1;      // 主队列
    Queue *q2;      // 辅助队列
} MyStack;

void myStackPush(MyStack *obj, int x) {
    // 1. 新元素放入 q2
    queuePush(obj->q2, x);
    // 2. q1 所有元素移到 q2
    while (!queueEmpty(obj->q1)) {
        queuePush(obj->q2, queuePop(obj->q1));
    }
    // 3. 交换 q1 和 q2
    Queue *temp = obj->q1;
    obj->q1 = obj->q2;
    obj->q2 = temp;
}

int myStackPop(MyStack *obj) {
    return queuePop(obj->q1);   // q1 队首就是栈顶
}

int myStackTop(MyStack *obj) {
    return queueFront(obj->q1);
}
```

### 6. 栈的应用：括号匹配

**概念：** 用栈判断表达式中的括号是否匹配。遇到左括号入栈，遇到右括号时检查栈顶是否与之匹配，匹配则出栈。

- **本质：** 后遇到的左括号先被匹配（LIFO）
- **算法：** 遍历字符，左括号入栈；右括号与栈顶比较

```c
int IsMatch(char open, char close) {
    return (open == '(' && close == ')') ||
           (open == '[' && close == ']') ||
           (open == '{' && close == '}');
}

int BracketMatch(char *expr) {
    Stack S;
    initStack(&S);
    for (int i = 0; expr[i] != '\0'; i++) {
        if (expr[i] == '(' || expr[i] == '[' || expr[i] == '{') {
            Push(&S, expr[i]);              // 左括号入栈
        } else if (expr[i] == ')' || expr[i] == ']' || expr[i] == '}') {
            if (IsEmpty(&S)) return 0;              // 栈空 → 右括号多余
            if (!IsMatch(Pop(&S), expr[i])) return 0; // 不匹配
        }
    }
    return IsEmpty(&S);                     // 栈空 → 全部匹配
}
```

### 7. 栈的应用：表达式求值（中缀转后缀）

**概念：** 中缀表达式（如 `a+b*c`）不符合人机习惯，需先转成后缀表达式（逆波兰式，如 `abc*+`）再求值。转换和求值都借助栈实现。

**中缀转后缀规则：**
- 操作数直接输出
- 左括号入栈
- 遇到运算符：当栈顶运算符优先级 ≥ 当前运算符时，栈顶出栈输出，再入栈当前运算符
- 右括号：弹出并输出直到遇到左括号

**后缀表达式求值：** 遇到操作数入栈，遇到运算符弹出两个操作数运算，结果压回栈。

```c
// 后缀表达式求值（操作数为单个数字）
int EvalPostfix(char *postfix) {
    Stack S;
    initStack(&S);
    for (int i = 0; postfix[i] != '\0'; i++) {
        char ch = postfix[i];
        if (ch >= '0' && ch <= '9') {
            Push(&S, ch - '0');             // 数字入栈
        } else {
            int b = Pop(&S);                // 先弹出的是右操作数
            int a = Pop(&S);
            int r;
            switch (ch) {
                case '+': r = a + b; break;
                case '-': r = a - b; break;
                case '*': r = a * b; break;
                case '/': r = a / b; break;
            }
            Push(&S, r);
        }
    }
    return Pop(&S);
}
```

**应用场景：** 计算器实现、编译器的表达式求值。

## 04 · 队列（Queue）

### 1. 队列的基本概念

**概念：** 队列是一种只允许在一端（队尾）插入、另一端（队首）删除的线性表。简称 FIFO（先进先出，First In First Out）。

- **核心操作：** `EnQueue（入队）`、`DeQueue（出队）`、`Peek（查看队首）`
- **生活类比：** 排队——先到先服务
- **应用场景：** BFS、任务调度、消息队列、缓冲区

### 2. 循环队列（数组实现）

**概念：** 用数组实现队列时，为了充分利用空间，将数组首尾相连形成循环。通过取模运算实现头尾指针的循环移动。

- **判空：** `count == 0` 或 `front == rear`
- **判满：** `count == maxsize - 1`（牺牲一个元素空间来区分空和满）
- **指针移动：** `front = (front + 1) % maxsize`

```c
#define maxsize 10

typedef struct Queue {
    int data[maxsize];
    int front;          // 队首指针
    int rear;           // 队尾指针
    int count;          // 当前元素个数
} Queue;

void InitQueue(Queue *q) {
    q->front = 0;
    q->rear = 0;
    q->count = 0;
}

bool IsEmpty(Queue *q) {
    return q->count == 0;
}

bool IsFull(Queue *q) {
    return q->count == maxsize - 1;    // 牺牲一个位置
}

// 入队
void EnQueue(Queue *q, int value) {
    if (IsFull(q)) return;
    q->data[q->rear] = value;
    q->rear = (q->rear + 1) % maxsize;  // 循环
    q->count++;
}

// 出队
int DeQueue(Queue *q) {
    if (IsEmpty(q)) return -1;
    int value = q->data[q->front];
    q->front = (q->front + 1) % maxsize;
    q->count--;
    return value;
}

// 查看队首
int Peek(Queue *q) {
    if (IsEmpty(q)) return -1;
    return q->data[q->front];
}

// 查看队尾
int Rear(Queue *q) {
    if (IsEmpty(q)) return -1;
    int last = (q->rear - 1 + maxsize) % maxsize;
    return q->data[last];
}
```

**队列的扩展操作（完整实现）：**

```c
// 反转队列
void ReverseQueue(Queue *q) {
    int temp[maxsize];
    int i = q->front;
    for (int j = 0; j < q->count; j++) {
        temp[j] = q->data[i];
        i = (i + 1) % maxsize;
    }
    i = q->front;
    for (int j = q->count - 1; j >= 0; j--) {
        q->data[i] = temp[j];
        i = (i + 1) % maxsize;
    }
}

// 合并队列（q2 并入 q1）
void MergeQueues(Queue *q1, Queue *q2) {
    if (IsEmpty(q2)) return;
    int i = q2->front;
    for (int j = 0; j < q2->count; j++) {
        if (!IsFull(q1)) EnQueue(q1, q2->data[i]);
        i = (i + 1) % maxsize;
    }
}

// 队列统计信息
int Sum(Queue *q) { /* 遍历求和 */ }
double Average(Queue *q) { return (double)Sum(q) / q->count; }
int Max(Queue *q) { /* 遍历找最大 */ }
int Min(Queue *q) { /* 遍历找最小 */ }
```

### 3. 链式队列（链表实现）

**概念：** 用链表实现队列，`front` 指向队首（出队端），`rear` 指向队尾（入队端）。

```c
typedef struct QueueNode {
    int val;
    struct QueueNode *next;
} QueueNode;

typedef struct {
    QueueNode *front;   // 队首指针（出队端）
    QueueNode *rear;    // 队尾指针（入队端）
} Queue;

void queuePush(Queue *q, int x) {
    QueueNode *newNode = (QueueNode*)malloc(sizeof(QueueNode));
    newNode->val = x;
    newNode->next = NULL;
    if (queueEmpty(q)) {
        q->front = q->rear = newNode;
    } else {
        q->rear->next = newNode;
        q->rear = newNode;
    }
}

int queuePop(Queue *q) {
    if (queueEmpty(q)) return -1;
    QueueNode *temp = q->front;
    int val = temp->val;
    q->front = q->front->next;
    if (q->front == NULL) {
        q->rear = NULL;     // 队列已空，rear也要置NULL
    }
    free(temp);
    return val;
}
```

**数组 vs 链式队列：**

| 对比 | 循环队列（数组） | 链式队列 |
|------|----------------|---------|
| 空间 | 固定大小 | 动态分配 |
| 操作效率 | O(1) | O(1) |
| 内存碎片 | 无 | 有（malloc/free） |
| 适合场景 | 大小已知 | 大小不定 |

### 4. 两个栈实现队列

**概念：** 使用两个栈模拟队列的 FIFO 特性。一个栈（inStack）负责入队，另一个栈（outStack）负责出队。

- **入队：** 直接压入 inStack
- **出队：** outStack 非空时直接出栈；outStack 为空时，先把 inStack 所有元素弹出并压入 outStack（此时元素顺序反转），再从 outStack 出栈

```c
typedef struct {
    Stack *inStack;     // 入队栈
    Stack *outStack;    // 出队栈
} MyQueue;

// 入队
void myQueuePush(MyQueue *obj, int x) {
    stackPush(obj->inStack, x);
}

// 内部：将 inStack 元素转移到 outStack（顺序反转）
void in2out(MyQueue *obj) {
    while (!stackEmpty(obj->inStack)) {
        int val = stackPop(obj->inStack);
        stackPush(obj->outStack, val);
    }
}

// 出队
int myQueuePop(MyQueue *obj) {
    if (stackEmpty(obj->outStack)) {
        in2out(obj);
    }
    return stackPop(obj->outStack);
}

// 查看队首
int myQueuePeek(MyQueue *obj) {
    if (stackEmpty(obj->outStack)) {
        in2out(obj);
    }
    return stackPeek(obj->outStack);
}

bool myQueueEmpty(MyQueue *obj) {
    return stackEmpty(obj->inStack) && stackEmpty(obj->outStack);
}
```

**摊销分析：** 每个元素最多被 push 两次（一次进 inStack、一次进 outStack）、pop 两次，总操作 O(1) 摊销。

## 05 · 树与二叉树

### 1. 树的基本概念

**概念：** 树是 n（n≥0）个节点的有限集合。n=0 时为空树。在任意一棵非空树中：
- 有且仅有一个根节点
- 其余节点分为 m 个互不相交的有限集合，每个集合又是一棵树（子树）

**术语：**
- **节点度：** 节点拥有的子树个数
- **叶子节点：** 度为 0 的节点（没有子节点）
- **非叶子节点：** 度不为 0 的节点
- **树的度：** 所有节点中最大的度
- **层：** 根为第 1 层，依次向下递增
- **深度/高度：** 树中节点的最大层数
- **森林：** m（m≥0）棵互不相交的树的集合

### 2. 二叉树的基本概念

**概念：** 二叉树是每个节点最多有两个子树的树结构，左子树和右子树有严格的顺序（不能颠倒）。

- **性质 1：** 第 i 层最多有 2^(i-1) 个节点（i≥1）
- **性质 2：** 深度为 k 的二叉树最多有 2^k - 1 个节点
- **性质 3：** 叶子节点数 = 度为 2 的节点数 + 1（n₀ = n₂ + 1）
- **满二叉树：** 每一层都是满的
- **完全二叉树：** 除最后一层外都是满的，且最后一层的所有节点靠左排列

```c
typedef struct TreeNode {
    int val;
    struct TreeNode *left;     // 左孩子指针
    struct TreeNode *right;    // 右孩子指针
} TreeNode;
```

### 3. 二叉树的遍历（递归实现）

**概念：** 遍历二叉树是指按某种规则访问每个节点一次。重点在于访问根节点的时机。

- **前序遍历：** 根 → 左 → 右（用于复制树、前缀表达式）
- **中序遍历：** 左 → 根 → 右（BST 中得到有序序列）
- **后序遍历：** 左 → 右 → 根（用于删除树、后缀表达式）
- **层序遍历：** 从上到下、从左到右（BFS）

```c
// 前序遍历
void PreOrderTraversal(BinTree Bt) {
    if (Bt) {
        printf("%d", Bt->data);             // 先访问根
        PreOrderTraversal(Bt->left);        // 再遍历左子树
        PreOrderTraversal(Bt->right);       // 最后遍历右子树
    }
}

// 中序遍历
void InOrderTraversal(BinTree Bt) {
    if (Bt) {
        InOrderTraversal(Bt->left);         // 先遍历左子树
        printf("%d", Bt->data);             // 访问根
        InOrderTraversal(Bt->right);        // 再遍历右子树
    }
}

// 后序遍历
void PastOrderTraversal(BinTree Bt) {
    if (Bt) {
        PastOrderTraversal(Bt->left);       // 先遍历左子树
        PastOrderTraversal(Bt->right);      // 再遍历右子树
        printf("%d", Bt->data);             // 最后访问根
    }
}
```

### 4. 二叉树的遍历（非递归实现）

**概念：** 非递归遍历使用栈来模拟递归过程。前序和中序遍历结构类似（访问时机不同），后序遍历需要双栈。

**中序遍历非递归（栈）：**
- 从根开始，一路向左走，边走边把节点入栈
- 当走到 NULL 时，出栈一个节点并访问
- 然后转向该节点的右子树，重复上述过程

```c
int* inorderTraversal(struct TreeNode* root, int* returnSize) {
    *returnSize = 0;
    if (root == NULL) return NULL;

    int* result = (int*)malloc(sizeof(int) * 100);
    struct TreeNode* stack[100];
    int top = -1;
    int idx = 0;

    struct TreeNode* curr = root;
    while (curr != NULL || top != -1) {
        while (curr != NULL) {              // 一路向左
            stack[++top] = curr;            // 节点入栈
            curr = curr->left;
        }
        curr = stack[top--];                // 出栈
        result[idx++] = curr->val;          // 访问（中序）
        curr = curr->right;                 // 转向右子树
    }

    *returnSize = idx;
    return result;
}
```

**前序遍历非递归（栈）：**

```c
int* preorderTraversal(struct TreeNode* root, int* returnSize) {
    // ... 初始化同上
    while (curr != NULL || top != -1) {
        while (curr != NULL) {
            result[idx++] = curr->val;      // 前序：访问时机在入栈时
            stack[++top] = curr;
            curr = curr->left;
        }
        curr = stack[top--];
        curr = curr->right;
    }
    return result;
}
```

**后序遍历非递归（双栈法）：**

```c
int* postorderTraversal(struct TreeNode* root, int* returnSize) {
    // 用两个栈实现
    struct TreeNode* stack1[100];
    struct TreeNode* stack2[100];
    int top1 = -1, top2 = -1;

    stack1[++top1] = root;
    while (top1 != -1) {
        struct TreeNode* node = stack1[top1--];
        stack2[++top2] = node;              // 入栈2（根先入）
        if (node->left)  stack1[++top1] = node->left;
        if (node->right) stack1[++top1] = node->right;
    }
    // 栈2 出栈顺序就是后序：左→右→根
    while (top2 != -1) {
        result[index++] = stack2[top2--]->val;
    }
    return result;
}
```

### 5. 层序遍历（队列实现）

**概念：** 从上到下、从左到右逐层访问每个节点，本质是广度优先搜索（BFS）。借助队列实现：访问某节点时，将其左右孩子依次入队，从而实现"先进先出、逐层扩散"。

- **数据结构：** 队列（FIFO）
- **特点：** 每一层的节点严格按从左到右的顺序被访问
- **时间复杂度：** O(n)，每个节点入队出队各一次

```c
void LevelOrderTraversal(BinTree Bt) {
    if (!Bt) return;
    Queue Q;                        // 借助队列（循环队列或链式队列）
    InitQueue(&Q);
    EnQueue(&Q, Bt);                // 根节点入队
    while (!IsEmpty(&Q)) {
        BinTree node = DeQueue(&Q); // 出队并访问
        printf("%d ", node->data);
        if (node->left)  EnQueue(&Q, node->left);   // 左孩子入队
        if (node->right) EnQueue(&Q, node->right);  // 右孩子入队
    }
}
```

**层序遍历的应用：**
- 求二叉树的高度（每遍历完一层层数加 1）
- 判断一棵树是否为完全二叉树（空节点之后不应再出现非空节点）
- 打印二叉树的树形结构（直观显示）

**四种遍历小结：**

| 遍历 | 顺序 | 数据结构 | 典型应用 |
|------|------|---------|---------|
| 前序 | 根→左→右 | 栈（递归） | 复制树、前缀表达式 |
| 中序 | 左→根→右 | 栈（递归） | BST 有序输出 |
| 后序 | 左→右→根 | 栈/双栈 | 删除树、后缀表达式 |
| 层序 | 逐层从左到右 | 队列 | 求高度、判断完全二叉树 |

### 6. 二叉搜索树（BST）

**概念：** 二叉搜索树是一棵二叉树，对任意节点，其左子树所有节点 < 根节点 < 右子树所有节点。

- **查找：** 比较根节点，小则向左，大则向右，相等则找到
- **插入：** 查找失败的位置就是插入位置
- **删除：** 三种情况——删除叶子（直接删）、删除只有一个子节点（子承父位）、删除有两个子节点（用右子树最小节点或左子树最大节点替换）

**查找（递归）：**
```c
Position Find(ElementType X, BinTree BST) {
    if (!BST) return NULL;
    if (X > BST->data) {
        return Find(X, BST->right);
    } else if (X < BST->data) {
        return Find(X, BST->left);
    } else {
        return BST;             // 查找成功
    }
}
```

**查找（迭代/尾递归优化）：**
```c
Position IterFind(ElementType X, BinTree BST) {
    while (BST) {
        if (X > BST->data) {
            BST = BST->right;
        } else if (X < BST->data) {
            BST = BST->left;
        } else {
            return BST;
        }
    }
    return NULL;                // 查找失败
}
```

**查找最小/最大值：**
- 最小值：最左边的节点（一路向左）
- 最大值：最右边的节点（一路向右）

```c
Position FindMin(BinTree BST) {
    if (!BST) return NULL;
    else if (!BST->left) return BST;        // 左子树为空，当前就是最小
    else return FindMin(BST->left);         // 继续向左

    /* 迭代版本
    if (BST) {
        while (BST->right) BST = BST->right;
    }
    return BST;
    */
}

Position FindMax(BinTree BST) {
    if (BST) {
        while (BST->right) BST = BST->right;
    }
    return BST;
}
```

**插入：**
```c
BinTree Insert(ElementType X, BinTree BST) {
    if (!BST) {
        BST = (TreeNode*)malloc(sizeof(TreeNode));
        BST->data = X;
        BST->left = BST->right = NULL;
    } else if (X < BST->data) {
        BST->left = Insert(X, BST->left);
    } else if (X > BST->data) {
        BST->right = Insert(X, BST->right);
    }
    return BST;
}
```

**删除（重要）：**
```c
BinTree Delete(ElementType X, BinTree BST) {
    Position Tmp;
    if (!BST) {
        printf("要删除的元素未找到\n");
    } else if (X < BST->data) {
        BST->left = Delete(X, BST->left);       // 左子树递归删除
    } else if (X > BST->data) {
        BST->right = Delete(X, BST->right);     // 右子树递归删除
    } else {                                    // 找到要删除的节点
        if (BST->left && BST->right) {          // 有两个子节点
            Tmp = FindMin(BST->right);          // 找右子树最小元素
            BST->data = Tmp->data;              // 替换为最小元素
            BST->right = Delete(BST->data, BST->right); // 删除右子树最小元素
        } else {                                // 有一个或没有子节点
            Tmp = BST;
            if (!BST->left)       BST = BST->right;
            else if (!BST->right) BST = BST->left;
            free(Tmp);
        }
    }
    return BST;
}
```

**删除核心思想：** 当被删除节点有两个子节点时，用右子树的最小节点（或左子树的最大节点）替换被删节点，然后删除那个替换节点。这样可以维持 BST 的性质。

### 7. 堆（Heap）

**概念：** 堆是一棵完全二叉树，可以用数组存储。最大堆：父节点 ≥ 子节点；最小堆：父节点 ≤ 子节点。

- **存储方式：** 数组，下标 i 的节点，左孩子 `2i+1`，右孩子 `2i+2`，父节点 `(i-1)/2`
- **核心操作：** 上浮（HeapifyUp）、下沉（HeapifyDown）
- **应用：** 堆排序、优先队列、Top K 问题

```c
typedef struct Heap {
    int *data;
    int size;
    int capacity;
} Heap;

Heap* CreateHeap(int capacity) {
    Heap *h = (Heap*)malloc(sizeof(Heap));
    h->data = (int*)malloc(sizeof(int) * capacity);
    h->size = 0;
    h->capacity = capacity;
    return h;
}
```

**上浮（插入时用）：**
```c
void HeapifyUp(Heap *h, int index) {
    while (index > 0) {
        int parent = (index - 1) / 2;
        if (h->data[parent] < h->data[index]) {    // 最大堆
            swap(&h->data[parent], &h->data[index]);
            index = parent;
        } else {
            break;
        }
    }
}
```

**下沉（删除堆顶时用）：**
```c
void HeapifyDown(Heap *h, int index) {
    int largest = index;
    int left = 2 * index + 1;
    int right = 2 * index + 2;

    if (left < h->size && h->data[left] > h->data[largest]) largest = left;
    if (right < h->size && h->data[right] > h->data[largest]) largest = right;

    if (largest != index) {
        swap(&h->data[index], &h->data[largest]);
        HeapifyDown(h, largest);
    }
}
```

**插入与删除：**
```c
void InsertHeap(Heap *h, int value) {
    if (h->size < h->capacity) {
        h->data[h->size] = value;
        HeapifyUp(h, h->size);          // 放到末尾，上浮到正确位置
        h->size++;
    }
}

int DeleteHeap(Heap *h) {
    if (h->size == 0) return -1;
    int root = h->data[0];
    h->data[0] = h->data[h->size - 1];  // 末尾元素移到堆顶
    h->size--;
    HeapifyDown(h, 0);                   // 下沉到正确位置
    return root;
}
```

**建堆（从数组构建堆）：**
```c
void BuildHeap(Heap *h, int *a, int n) {
    for (int i = 0; i < n; i++) {
        h->data[i] = a[i];
    }
    h->size = n;
    for (int i = n / 2 - 1; i >= 0; i--) {
        HeapifyDown(h, i);              // 从最后一个非叶子节点开始
    }
}
```

**合并两个堆：**
```c
Heap* MergeHeaps(Heap *h1, Heap *h2) {
    int totalsize = h1->size + h2->size;
    Heap *newh = CreateHeap(totalsize);
    int i;
    for (i = 0; i < h1->size; i++) newh->data[i] = h1->data[i];
    for (i = 0; i < h2->size; i++) newh->data[h1->size + i] = h2->data[i];
    newh->size = totalsize;
    for (i = totalsize / 2 - 1; i >= 0; i--) {
        HeapifyDown(newh, i);
    }
    return newh;
}
```

### 8. 二叉树的顺序存储

**概念：** 用一维数组存储二叉树，按下标关系把树填入数组。下标从 1 开始，节点 i 的左孩子是 2i，右孩子是 2i+1，父节点是 ⌊i/2⌋。

- **下标关系（下标从 1 开始）：** 左孩子 `2i`，右孩子 `2i+1`，父节点 `⌊i/2⌋`
- **适用场景：** 完全二叉树特别适合顺序存储，无空间浪费
- **非完全二叉树的缺点：** 需按完全二叉树补空位，可能浪费大量空间
- **与堆排序下标差异：** 堆排序中下标从 0 开始，左孩子为 `2i+1`，右孩子为 `2i+2`，父节点为 `(i-1)/2`

```c
// 顺序存储：下标从 1 开始
// 节点 i 的左孩子：2*i，右孩子：2*i+1，父节点：i/2
#define MAXSIZE 100
typedef int ElemType;
ElemType tree[MAXSIZE];     // 数组本身即顺序存储的二叉树

// 判断节点 i 是否为叶子节点（无孩子）
int IsLeaf(int i, int n) {
    return (2 * i > n);     // 2i 越界说明没有左孩子，即为叶子
}
```

**链式 vs 顺序存储：**

| 对比 | 顺序存储（数组） | 链式存储（指针） |
|------|----------------|-----------------|
| 空间 | 完全二叉树省，斜树浪费大 | 与节点数成正比 |
| 找父节点 | O(1)，i/2 | 需 parent 指针，否则 O(n) |
| 插入/删除 | 可能涉及移动元素 | 纯指针操作 |
| 适合场景 | 完全二叉树、堆 | 一般二叉树 |

### 9. 由遍历序列恢复二叉树

**概念：** 给定中序遍历序列 + （前序或后序）遍历序列，可唯一确定一棵二叉树。前序/后序用来确定根，中序用来划分左右子树。

- **前序 + 中序：** 前序第一个元素是根；在中序中找到根，其左边是左子树、右边是右子树
- **后序 + 中序：** 后序最后一个元素是根；划分方式同前序 + 中序
- **前序 + 后序不能唯一确定：** 只有单孩子的节点无法判断是左孩子还是右孩子

```c
// 前序 + 中序 恢复二叉树
// pre[l1..r1] 为前序序列，in[l2..r2] 为中序序列
BinTree BuildByPreIn(int *pre, int *in, int l1, int r1, int l2, int r2) {
    if (l1 > r1) return NULL;
    BinTree root = (BinTree)malloc(sizeof(TreeNode));
    root->data = pre[l1];               // 前序第一个元素是根

    int k = l2;                         // 在中序中找根的位置 k
    while (in[k] != pre[l1]) k++;
    int leftLen = k - l2;               // 左子树节点个数

    root->left  = BuildByPreIn(pre, in, l1 + 1, l1 + leftLen, l2, k - 1);
    root->right = BuildByPreIn(pre, in, l1 + leftLen + 1, r1, k + 1, r2);
    return root;
}
```

### 10. 线索二叉树

**概念：** 利用二叉链表中的空指针域存放节点的"前驱"和"后继"信息，使遍历不需要递归或栈。指向前驱/后继的指针称为**线索**（thread）。

- **空指针利用：** 原 left 为空 → 指向前驱；原 right 为空 → 指向后继
- **标志位：** 用 `ltag`/`rtag` 区分孩子指针还是线索（0 = 孩子，1 = 线索）
- **中序线索树最常用：** 可快速找到某节点的中序前驱/后继
- **优点：** 不用递归、不用栈即可遍历，且利用空指针不浪费空间

```c
typedef struct ThreadNode {
    int data;
    struct ThreadNode *left, *right;
    int ltag, rtag;     // 0 表示孩子，1 表示线索
} ThreadNode, *ThreadTree;

ThreadNode *pre = NULL;     // 全局变量：指向当前访问节点的前驱

// 中序线索化（递归）
void InThread(ThreadTree p) {
    if (p) {
        InThread(p->left);                  // 线索化左子树
        if (p->left == NULL) {              // 左指针为空 → 指向前驱
            p->left = pre;
            p->ltag = 1;
        }
        if (pre != NULL && pre->right == NULL) { // 前驱右指针为空 → 指向当前
            pre->right = p;
            pre->rtag = 1;
        }
        pre = p;
        InThread(p->right);                 // 线索化右子树
    }
}

// 求中序线索树中节点 p 的中序后继
ThreadNode* NextNode(ThreadNode *p) {
    if (p->rtag == 1) return p->right;      // 有线索，直接返回后继
    p = p->right;                           // 否则右子树中最左的节点
    while (p->ltag == 0) p = p->left;
    return p;
}
```

### 11. 哈夫曼树与哈夫曼编码

**概念：** 哈夫曼树（最优二叉树）是带权路径长度（WPL）最小的二叉树。权值越大的节点离根越近。常用来构造前缀编码（哈夫曼编码），是压缩算法的核心。

- **带权路径长度 WPL：** 所有叶子节点的（权值 × 路径长度）之和
- **构造步骤：**
  1. 把所有节点按权值放入集合（升序）
  2. 每次取权值最小的两个节点作为左右孩子，合并成一个权值为两者之和的新节点
  3. 新节点放回集合，重复直到只剩一个根节点
- **特点：** 权值越大越靠近根；哈夫曼树中没有度为 1 的节点

```c
typedef struct HNode {
    int weight;                 // 权值
    int parent, lchild, rchild; // 静态三叉链表（数组下标代替指针）
} HNode;

// 构造哈夫曼树：n 个叶子 → 共 2n-1 个节点
void CreateHuffmanTree(HNode ht[], int n) {
    int total = 2 * n - 1;
    for (int i = 0; i < total; i++) {       // 初始化
        ht[i].parent = ht[i].lchild = ht[i].rchild = -1;
    }
    for (int i = n; i < total; i++) {
        // 找两个权值最小且尚无父节点的节点 m1, m2
        int m1 = -1, m2 = -1;
        for (int j = 0; j < i; j++) {
            if (ht[j].parent == -1) {
                if (m1 == -1 || ht[j].weight < ht[m1].weight) { m2 = m1; m1 = j; }
                else if (m2 == -1 || ht[j].weight < ht[m2].weight) { m2 = j; }
            }
        }
        ht[m1].parent = i; ht[m2].parent = i;   // 两个子树挂到新双亲
        ht[i].lchild = m1; ht[i].rchild = m2;
        ht[i].weight = ht[m1].weight + ht[m2].weight;
    }
}
```

**哈夫曼编码：**
- 从根到叶子的路径上，走左孩子记 0，走右孩子记 1
- **前缀编码：** 任一字符的编码都不是另一个字符编码的前缀，可无歧义解码
- **压缩原理：** 出现频率高的字符用短编码，频率低的用长编码

**应用：** 文件压缩（ZIP）、无损数据压缩、决策树优化。

### 12. 树与森林

**概念：** 树的存储方式常用双亲表示法、孩子表示法、孩子兄弟表示法（二叉链表）。

| 存储方法 | 原理 | 优点 | 缺点 |
|---------|------|------|------|
| 双亲表示法 | 存每个节点的双亲下标 | 易找双亲 | 找孩子需遍历 |
| 孩子表示法 | 每个节点带一个孩子链表 | 易找孩子 | 找双亲需遍历 |
| 孩子兄弟表示法 | 左孩子 + 右兄弟两个指针 | 易转换为二叉树 | 找双亲需遍历 |

```c
// 孩子兄弟表示法
typedef struct CSNode {
    int data;
    struct CSNode *firstChild;   // 第一个孩子
    struct CSNode *nextSibling;  // 下一个兄弟
} CSNode, *CSTree;
```

**树的遍历：**
- **先根遍历：** 先访问根，再依次先根遍历每棵子树（对应二叉树的前序遍历）
- **后根遍历：** 先依次后根遍历每棵子树，再访问根（对应二叉树的中序遍历）
- **层次遍历：** 与二叉树层序相同（队列实现）

**森林：** m（m≥0）棵互不相交的树的集合。

### 13. 树/森林与二叉树的转换

**概念：** 用"孩子兄弟表示法"可以把任意树转换为二叉树。森林通过给各树加一个虚拟根，也可转换为二叉树。

**树 → 二叉树（孩子兄弟法）：**
- 左指针指向第一个孩子
- 右指针指向下一个兄弟（兄弟转为右子树）
- 转换后根节点没有右孩子

**二叉树 → 树：** 逆过程——右子树拆回兄弟链，左子树保留为第一个孩子。

**森林 → 二叉树：** 先把每棵树转为二叉树，再依次把后一棵树的根作为前一棵树根的右孩子。

```c
// 树（孩子兄弟表示）→ 二叉树
BinTree TreeToBinary(CSTree t) {
    if (t == NULL) return NULL;
    BinTree bt = (BinTree)malloc(sizeof(TreeNode));
    bt->data = t->data;
    bt->left  = TreeToBinary(t->firstChild);   // 第一个孩子 → 左子树
    bt->right = TreeToBinary(t->nextSibling);  // 下一个兄弟 → 右子树
    return bt;
}
```

**转换的意义：** 借助二叉树的成熟算法（遍历、查找等）来处理树与森林的问题。

### 14. 平衡二叉树（AVL）

**概念：** 平衡二叉树是任意节点左右子树高度差不超过 1 的二叉搜索树，可避免 BST 退化为链表导致查找变慢。

- **平衡因子（BF）：** BF = 左子树高度 − 右子树高度，只能取 −1、0、1
- **失衡类型：** LL（左左）、RR（右右）、LR（左右）、RL（右左）
- **调整方式：** LL 右旋、RR 左旋、LR 先左旋再右旋、RL 先右旋再左旋

**四种失衡与调整：**

| 失衡类型 | 触发场景 | 调整 |
|---------|---------|------|
| LL | 在左孩子的左子树插入 | 右旋一次 |
| RR | 在右孩子的右子树插入 | 左旋一次 |
| LR | 在左孩子的右子树插入 | 先左旋后右旋 |
| RL | 在右孩子的左子树插入 | 先右旋后左旋 |

```c
typedef struct AVLNode {
    int data;
    int height;                  // 该节点的高度（子树高度）
    struct AVLNode *left, *right;
} AVLNode, *AVLTree;

int Height(AVLTree t) { return t ? t->height : 0; }

// 右旋（LL 型失衡）
AVLTree RotateRight(AVLTree y) {
    AVLTree x = y->left;
    y->left = x->right;
    x->right = y;
    y->height = max(Height(y->left), Height(y->right)) + 1;
    x->height = max(Height(x->left), Height(x->right)) + 1;
    return x;                    // 返回新的根
}

// 左旋（RR 型失衡）与右旋对称
AVLTree RotateLeft(AVLTree x) {
    AVLTree y = x->right;
    x->right = y->left;
    y->left = x;
    x->height = max(Height(x->left), Height(x->right)) + 1;
    y->height = max(Height(y->left), Height(y->right)) + 1;
    return y;
}

// 插入后检查并恢复平衡
AVLTree InsertAVL(AVLTree t, int key) {
    if (t == NULL) {
        AVLTree node = (AVLTree)malloc(sizeof(AVLNode));
        node->data = key; node->height = 1;
        node->left = node->right = NULL;
        return node;
    }
    if (key < t->data)      t->left  = InsertAVL(t->left, key);
    else if (key > t->data) t->right = InsertAVL(t->right, key);
    else return t;

    t->height = max(Height(t->left), Height(t->right)) + 1;
    int bf = Height(t->left) - Height(t->right);

    // 四种失衡分别旋转
    if (bf > 1 && key < t->left->data)      return RotateRight(t);      // LL
    if (bf < -1 && key > t->right->data)    return RotateLeft(t);       // RR
    if (bf > 1 && key > t->left->data) {                                // LR
        t->left = RotateLeft(t->left);
        return RotateRight(t);
    }
    if (bf < -1 && key < t->right->data) {                              // RL
        t->right = RotateRight(t->right);
        return RotateLeft(t);
    }
    return t;
}
```

**AVL 查找/插入/删除复杂度：** 始终 O(log n)，因为树高被严格限制在 O(log n)。相比普通 BST 的最坏 O(n)，AVL 保证了稳定的查找性能。

### 15. 二叉树经典递归应用

**概念：** 许多二叉树问题用"分治"递归解决：先递归处理左、右子树，再把两者的结果汇总到根节点。这是二叉树算法的核心套路。

**求树的高度：**
```c
int TreeHeight(BinTree Bt) {
    if (!Bt) return 0;
    int leftH  = TreeHeight(Bt->left);
    int rightH = TreeHeight(Bt->right);
    return (leftH > rightH ? leftH : rightH) + 1;
}
```

**求节点总数：**
```c
int CountNodes(BinTree Bt) {
    if (!Bt) return 0;
    return CountNodes(Bt->left) + CountNodes(Bt->right) + 1;
}
```

**求叶子节点数：**
```c
int CountLeaves(BinTree Bt) {
    if (!Bt) return 0;
    if (!Bt->left && !Bt->right) return 1;      // 叶子节点
    return CountLeaves(Bt->left) + CountLeaves(Bt->right);
}
```

**镜像二叉树（翻转）：**
```c
void Mirror(BinTree Bt) {
    if (!Bt) return;
    BinTree temp = Bt->left;        // 交换左右子树
    Bt->left = Bt->right;
    Bt->right = temp;
    Mirror(Bt->left);
    Mirror(Bt->right);
}
```

**判断是否平衡（AVL 思想）：**
```c
int IsBalanced(BinTree Bt) {
    if (!Bt) return 1;
    int l = TreeHeight(Bt->left);
    int r = TreeHeight(Bt->right);
    if (abs(l - r) > 1) return 0;                       // 失衡
    return IsBalanced(Bt->left) && IsBalanced(Bt->right);
}
```

**套路总结：** 先递归求左、右子树的解，再用左右结果推出根的解（分治、自底向上）。通用模板就是 `result = combine(solve(left), solve(right))`。

## 06 · 图（Graph）

### 1. 图的基本概念

**概念：** 图 G(V, E) 由顶点集合 V 和边集合 E 组成。图是一种非线性数据结构，可以描述多对多的关系。

| 术语 | 含义 |
|------|------|
| 有向图 | 边有方向（箭头），如 A→B |
| 无向图 | 边无方向，如 A—B |
| 完全图 | 任意两个顶点之间都有边 |
| 度 | 无向图中顶点关联的边数 |
| 入度/出度 | 有向图中指向顶点的边数/从顶点出发的边数 |
| 路径 | 顶点序列，相邻顶点之间有边 |
| 连通图 | 任意两个顶点之间都有路径 |
| 权 | 边的长度或代价 |
| 邻接点 | 有边直接相连的两个顶点 |

**图的存储方式：**
- **邻接矩阵：** 二维数组，O(n²) 空间，适合稠密图
- **邻接表：** 链表数组，O(n+e) 空间，适合稀疏图

### 2. 邻接矩阵（Array/Matrix）

**概念：** 用二维数组 `matrix[n][n]` 表示 n 个顶点的图。`matrix[i][j]` 表示顶点 i 到 j 的边（0 表示无边，非 0 表示有权）。

```c
#define MAX_VERTICES 100

typedef struct {
    int vertexCount;
    int edgeCount;
    int matrix[MAX_VERTICES][MAX_VERTICES];
    char vertexData[MAX_VERTICES];      // 顶点名称（A， B, C...）
} MatrixGraph;

MatrixGraph* createMatrixGraph(int vertexCount) {
    MatrixGraph *graph = (MatrixGraph*)malloc(sizeof(MatrixGraph));
    graph->vertexCount = vertexCount;
    graph->edgeCount = 0;
    for (int i = 0; i < vertexCount; i++) {
        graph->vertexData[i] = 'A' + i;     // 默认 A, B, C...
        for (int j = 0; j < vertexCount; j++) {
            graph->matrix[i][j] = 0;        // 0 表示无边
        }
    }
    return graph;
}

void addEdgeToMatrix(MatrixGraph *graph, int start, int end, int weight, bool isUndirected) {
    graph->matrix[start][end] = weight;
    if (isUndirected) {
        graph->matrix[end][start] = weight; // 无向图对称
    }
    graph->edgeCount++;
}

void printMatrixGraph(MatrixGraph *graph) {
    printf("     ");
    for (int i = 0; i < graph->vertexCount; i++) {
        printf(" %c(%d) ", graph->vertexData[i], i);
    }
    printf("\n");
    for (int i = 0; i < graph->vertexCount; i++) {
        printf("%c(%d): ", graph->vertexData[i], i);
        for (int j = 0; j < graph->vertexCount; j++) {
            printf(" %3d ", graph->matrix[i][j]);
        }
        printf("\n");
    }
}
```

### 3. 邻接表（Adjacency List）

**概念：** 每个顶点对应一个链表，链表中存储该顶点的所有邻接点。适合稀疏图。

```c
typedef struct AdjListNode {
    int vertex;                     // 邻接顶点
    int weight;                     // 边权
    struct AdjListNode *next;
} AdjListNode;

typedef struct {
    AdjListNode *head;
    char data;
} AdjList;

typedef struct {
    int vertexCount;
    int edgeCount;
    AdjList lists[MAX_VERTICES];
} ListGraph;

ListGraph* createListGraph(int vertexCount) {
    ListGraph *graph = (ListGraph*)malloc(sizeof(ListGraph));
    graph->vertexCount = vertexCount;
    graph->edgeCount = 0;
    for (int i = 0; i < vertexCount; i++) {
        graph->lists[i].head = NULL;
        graph->lists[i].data = 'A' + i;
    }
    return graph;
}

void addEdgeToList(ListGraph *graph, int start, int end, int weight, bool isUndirected) {
    AdjListNode *newNode = (AdjListNode*)malloc(sizeof(AdjListNode));
    newNode->vertex = end;
    newNode->weight = weight;
    newNode->next = graph->lists[start].head;   // 头插法
    graph->lists[start].head = newNode;

    if (isUndirected) {                         // 无向图加反向边
        newNode = (AdjListNode*)malloc(sizeof(AdjListNode));
        newNode->vertex = start;
        newNode->weight = weight;
        newNode->next = graph->lists[end].head;
        graph->lists[end].head = newNode;
    }
    graph->edgeCount++;
}

void printListGraph(ListGraph *graph) {
    for (int i = 0; i < graph->vertexCount; i++) {
        printf("%c(%d): ", graph->lists[i].data, i);
        AdjListNode *curr = graph->lists[i].head;
        while (curr) {
            printf("->%c(%d)[%d]", graph->lists[curr->vertex].data, curr->vertex, curr->weight);
            curr = curr->next;
        }
        printf("\n");
    }
}
```

**邻接矩阵 vs 邻接表：**

| 对比 | 邻接矩阵 | 邻接表 |
|------|---------|-------|
| 空间 | O(n²) | O(n+e) |
| 查边(u,v) | O(1) | O(degree(u)) |
| 遍历邻接点 | O(n) | O(degree(u)) |
| 适合图 | 稠密图 | 稀疏图 |

### 4. 深度优先搜索（DFS）

**概念：** 从某个顶点出发，访问它，然后递归地访问它的未访问过的邻接点。类似树的"前序遍历"。

- **本质：** 一条路走到黑，走不通再回溯
- **数据结构：** 栈（递归调用栈）
- **时间复杂度：** O(n+e) 邻接表，O(n²) 邻接矩阵

```c
bool visited[MAX_VERTICES];

void DFS_Recursive(Graph *graph, int v) {
    printf("访问顶点: %c(%d)\n", graph->vertices[v].data, v);
    visited[v] = true;

    // 遍历所有邻接点
    AdjListNode *current = graph->vertices[v].head;
    while (current != NULL) {
        int neighbor = current->vertex;
        if (!visited[neighbor]) {
            DFS_Recursive(graph, neighbor);
        }
        current = current->next;
    }
}

void DFS_Traversal(Graph *graph) {
    for (int i = 0; i < graph->Nv; i++) visited[i] = false;
    for (int i = 0; i < graph->Nv; i++) {
        if (!visited[i]) {
            DFS_Recursive(graph, i);    // 处理非连通图
        }
    }
}
```

### 5. 广度优先搜索（BFS）

**概念：** 从某个顶点出发，先访问它，然后依次访问它的所有邻接点，再依次访问这些邻接点的邻接点。类似树的"层序遍历"。

- **本质：** 分层扩散，先近后远
- **数据结构：** 队列
- **时间复杂度：** O(n+e) 邻接表，O(n²) 邻接矩阵
- **应用：** 无权图的最短路径

```c
void BFS_Traversal(Graph *graph, int start) {
    bool visited[MAX_VERTICES] = {false};
    Queue queue;
    Queue_Init(&queue);

    visited[start] = true;
    Queue_Enqueue(&queue, start);

    while (!Queue_IsEmpty(&queue)) {
        int v = Queue_Dequeue(&queue);
        printf("访问顶点: %c(%d)\n", graph->vertices[v].data, v);

        AdjListNode *current = graph->vertices[v].head;
        while (current != NULL) {
            int neighbor = current->vertex;
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                Queue_Enqueue(&queue, neighbor);
            }
            current = current->next;
        }
    }
}
```

**DFS vs BFS：**

| 对比 | DFS | BFS |
|------|-----|-----|
| 数据结构 | 栈（递归/显式） | 队列 |
| 策略 | 深入优先 | 广度优先 |
| 适用 | 连通性检测、拓扑排序 | 最短路径、层次遍历 |
| 空间 | O(h)，h 为深度 | O(w)，w 为宽度（通常更大） |

### 6. 无权图单源最短路径（BFS）

**概念：** 在无权图中，BFS 天然能找到从源点到其他所有顶点的最短路径（边数最少）。

```c
void BFS_ShortestPath(Graph *graph, int src) {
    int distance[MAX_VERTEX];
    int parent[MAX_VERTEX];     // 记录路径前驱

    for (int i = 0; i < graph->V; i++) {
        distance[i] = -1;       // -1 表示不可达
        parent[i] = -1;
    }

    int queue[MAX_VERTEX], front = 0, rear = 0;
    visited[src] = true;
    distance[src] = 0;
    queue[rear++] = src;

    while (front < rear) {
        int current = queue[front++];
        Node *temp = graph->array[current].head;
        while (temp != NULL) {
            int neighbor = temp->vertex;
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                distance[neighbor] = distance[current] + 1;
                parent[neighbor] = current;         // 记录路径
                queue[rear++] = neighbor;
            }
            temp = temp->next;
        }
    }
    // 通过 parent 数组回溯打印路径
}
```

### 7. Dijkstra 算法（带权图最短路径）

**概念：** 求带权图中单源最短路径的经典算法。贪心策略：每次选距离源点最近且未访问的顶点，用该顶点更新其邻接点的距离。

- **适用条件：** 边权非负
- **时间复杂度：** 朴素 O(n²)，堆优化 O((n+e) log n)
- **核心步骤：**
  1. 初始化 dist[src]=0，其他 dist=∞
  2. 循环 n 次：选未访问的 dist 最小顶点 u，标记 u 已访问，用 u 更新邻接点 dist

```c
void dijkstra(int graph[V][V], int src) {
    int dist[V], parent[V];
    bool visited[V] = {false};

    for (int i = 0; i < V; i++) {
        dist[i] = INT_MAX;
        parent[i] = -1;
    }
    dist[src] = 0;

    for (int count = 0; count < V - 1; count++) {
        // 选未访问的 dist 最小顶点
        int u = -1, minDist = INT_MAX;
        for (int i = 0; i < V; i++) {
            if (!visited[i] && dist[i] < minDist) {
                minDist = dist[i];
                u = i;
            }
        }
        if (u == -1) break;
        visited[u] = true;

        // 更新邻接点
        for (int v = 0; v < V; v++) {
            if (graph[u][v] && !visited[v] &&
                dist[u] != INT_MAX &&
                dist[u] + graph[u][v] < dist[v]) {
                dist[v] = dist[u] + graph[u][v];
                parent[v] = u;
            }
        }
    }
}
```

### 8. Kruskal 算法（最小生成树）

**概念：** 按边权从小到大选择边，如果加入该边不会形成环，则加入。使用并查集（Disjoint Set）检测环。

```c
typedef struct Edge {
    int start;
    int end;
    int weight;
} Edge;

// 并查集
typedef struct DisjointSet {
    int parent[maxsize];
    int rank[maxsize];
} DisjointSet;

void InitDisjointSet(DisjointSet *set, int n) {
    for (int i = 0; i < n; i++) {
        set->parent[i] = i;     // 初始时每个节点是自己的父节点
        set->rank[i] = 0;
    }
}

int FindSet(DisjointSet *set, int x) {
    if (set->parent[x] != x) {
        set->parent[x] = FindSet(set, set->parent[x]);  // 路径压缩
    }
    return set->parent[x];
}

void UnionSet(DisjointSet *set, int x, int y) {
    int rootX = FindSet(set, x);
    int rootY = FindSet(set, y);
    if (rootX != rootY) {
        if (set->rank[rootX] > set->rank[rootY]) {
            set->parent[rootY] = rootX;
        } else if (set->rank[rootX] < set->rank[rootY]) {
            set->parent[rootX] = rootY;
        } else {
            set->parent[rootY] = rootX;
            set->rank[rootX]++;
        }
    }
}

int CompareEdges(const void *a, const void *b) {
    return ((Edge*)a)->weight - ((Edge*)b)->weight;
}

void KruskalMST(Graph *graph) {
    Edge edges[maxsize * maxsize];
    int edgeCount = 0;
    // 收集所有边
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (graph->matrix[i][j] != 0) {
                edges[edgeCount++] = (Edge){i, j, graph->matrix[i][j]};
            }
        }
    }
    qsort(edges, edgeCount, sizeof(Edge), CompareEdges);  // 按权排序

    DisjointSet set;
    InitDisjointSet(&set, n);

    int totalWeight = 0;
    for (int i = 0; i < edgeCount; i++) {
        if (FindSet(&set, edges[i].start) != FindSet(&set, edges[i].end)) {
            UnionSet(&set, edges[i].start, edges[i].end);
            printf("%c->%c : (%d)\n", graph->vertexData[edges[i].start],
                   graph->vertexData[edges[i].end], edges[i].weight);
            totalWeight += edges[i].weight;
        }
    }
}
```

**并查集两个核心优化：**
1. **路径压缩：** find 时把沿途所有节点直接指向根节点
2. **按秩合并：** 将秩小的树合并到秩大的树上

### 9. Prim 算法（最小生成树）

**概念：** Prim 算法从任意顶点开始，每次选择"连接已选顶点集合"与"未选顶点集合"的权值最小的一条边，把新顶点加入集合，直到所有顶点都在集合中。

- **核心：** `lowcost` 数组记录每个未选顶点到已选集合的最小边权
- **时间复杂度：** 朴素 O(n²)，堆优化 O((n+e) log n)
- **适用：** 稠密图

```c
void Prim(int graph[V][V]) {
    int lowcost[V];     // 到已选集合的最小权值
    int parent[V];      // 记录 MST 中的父节点
    int visited[V] = {false};

    for (int i = 0; i < V; i++) {
        lowcost[i] = graph[0][i];   // 从顶点 0 开始
        parent[i] = 0;
    }
    visited[0] = true;

    for (int cnt = 0; cnt < V - 1; cnt++) {
        int min = INT_MAX, u = -1;
        for (int i = 0; i < V; i++) {       // 找权值最小的未选顶点
            if (!visited[i] && lowcost[i] < min) {
                min = lowcost[i];
                u = i;
            }
        }
        visited[u] = true;
        printf("%d->%d (%d)\n", parent[u], u, lowcost[u]);
        for (int i = 0; i < V; i++) {       // 更新 lowcost
            if (!visited[i] && graph[u][i] && graph[u][i] < lowcost[i]) {
                lowcost[i] = graph[u][i];
                parent[i] = u;
            }
        }
    }
}
```

**Prim vs Kruskal：**

| 对比 | Prim | Kruskal |
|------|------|---------|
| 思路 | 从顶点出发逐步扩展 | 边权从小到大选边 |
| 数据结构 | lowcost 数组 | 并查集 |
| 时间复杂度 | O(n²) | O(e log e) |
| 适合图 | 稠密图 | 稀疏图 |

### 10. 拓扑排序

**概念：** 拓扑排序是把有向无环图（DAG）的顶点排成一个线性序列，使得对每条有向边 u→v，u 都排在 v 之前。常用于任务调度、课程安排、编译依赖。

- **核心：** 每次选一个入度为 0 的顶点输出，并删除它及其出边
- **前提：** 必须是有向无环图（有环则无法拓扑排序）
- **数据结构：** 队列（存入度为 0 的顶点）+ 入度数组

```c
void TopologicalSort(Graph *g) {
    int indegree[V] = {0};
    for (int u = 0; u < g->Nv; u++) {
        for (AdjListNode *p = g->lists[u].head; p; p = p->next) {
            indegree[p->vertex]++;          // 统计入度
        }
    }
    Queue Q;
    InitQueue(&Q);
    for (int i = 0; i < g->Nv; i++) {
        if (indegree[i] == 0) EnQueue(&Q, i);   // 入度为 0 入队
    }
    int count = 0;
    while (!IsEmpty(&Q)) {
        int u = DeQueue(&Q);
        printf("%d ", u);                   // 输出
        count++;
        for (AdjListNode *p = g->lists[u].head; p; p = p->next) {
            if (--indegree[p->vertex] == 0) EnQueue(&Q, p->vertex);
        }
    }
    if (count != g->Nv) printf("存在环，无法拓扑排序\n");
}
```

**应用：** 工程进度安排、课程先修关系、编译器依赖分析。

### 11. Floyd 算法（多源最短路径）

**概念：** Floyd 算法求图中所有顶点对之间的最短路径。核心是动态规划：依次以每个顶点 k 作为中间点，尝试更新 `dist[i][j]`。

- **状态转移：** `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`
- **时间复杂度：** O(n³)
- **优点：** 代码简单，可处理负权边（但不能有负权环）

```c
void Floyd(int graph[V][V]) {
    int dist[V][V], path[V][V];
    for (int i = 0; i < V; i++)             // 初始化
        for (int j = 0; j < V; j++) {
            dist[i][j] = graph[i][j];
            path[i][j] = -1;
        }

    for (int k = 0; k < V; k++) {           // 中间点
        for (int i = 0; i < V; i++) {
            for (int j = 0; j < V; j++) {
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                    path[i][j] = k;         // 记录中间点
                }
            }
        }
    }
}
```

**Dijkstra vs Floyd：**

| 对比 | Dijkstra | Floyd |
|------|---------|-------|
| 求解 | 单源（一个源点） | 多源（所有顶点对） |
| 负权边 | 不支持 | 支持（无负环） |
| 时间复杂度 | O(n²) | O(n³) |

### 12. 关键路径（AOE 网）

**概念：** AOE 网是带权的有向无环图，顶点表示事件，边表示活动，边权表示活动耗时。关键路径是从源点到汇点的最长路径，决定整个工程的最短完成时间。

- **关键活动：** 关键路径上的活动延误会推迟总工期；非关键活动延误不一定影响总工期
- **最早发生时间 ve：** 从源点正向推，取最大值
- **最迟发生时间 vl：** 从汇点反向推，取最小值
- **关键活动判定：** 活动的最早开始时间 == 最迟开始时间

```c
// 步骤：先拓扑排序求 ve，再逆拓扑求 vl，最后比较判定关键活动
// ve[k]  = max(ve[j] + w(j, k))       正向递推
// vl[j]  = min(vl[k] - w(j, k))       反向递推
// 活动 a(i, j) 最早开始 = ve[i]，最迟开始 = vl[j] - w(i, j)
// 最早 == 最迟 的活动即为关键活动
```

**应用：** 工程管理（建筑、软件开发等），找出决定总工期的关键活动。

## 07 · 哈希表（Hash Table）

### 1. 哈希表的基本概念

**概念：** 哈希表（散列表）通过哈希函数将键（key）映射到数组的某个位置，实现 O(1) 的平均查找时间。

- **哈希函数：** `index = hash(key) % TABLE_SIZE`
- **冲突：** 不同的 key 映射到同一个位置
- **负载因子：** 已存元素 / 总容量，越大冲突越多
- **解决冲突的方法：** 链地址法（常用）、开放地址法、再哈希法

### 2. 链地址法哈希表

**概念：** 每个数组位置是一个链表的头指针，冲突的元素挂在同一个链表中。

```c
#define TABLE_SIZE 100

typedef struct Node {
    char key[50];
    int value;
    struct Node *next;
} Node;

typedef struct {
    Node *buckets[TABLE_SIZE];   // 每个桶是链表头指针
} HashTable;

// 哈希函数（字符串ASCII码求和）
int hash(char *key) {
    int sum = 0;
    for (int i = 0; key[i] != '\0'; i++) {
        sum += key[i];
    }
    return sum % TABLE_SIZE;
}

HashTable* createTable() {
    HashTable *table = (HashTable*)malloc(sizeof(HashTable));
    for (int i = 0; i < TABLE_SIZE; i++) {
        table->buckets[i] = NULL;
    }
    return table;
}

// 插入（头插法）
void insert(HashTable *table, char *key, int value) {
    int index = hash(key);
    Node *newNode = (Node*)malloc(sizeof(Node));
    strcpy(newNode->key, key);
    newNode->value = value;
    newNode->next = table->buckets[index];   // 头插
    table->buckets[index] = newNode;
}

// 查找
int* search(HashTable *table, char *key) {
    int index = hash(key);
    Node *current = table->buckets[index];
    while (current != NULL) {
        if (strcmp(current->key, key) == 0) {
            return &(current->value);       // 返回值的地址
        }
        current = current->next;
    }
    return NULL;                            // 没找到
}

// 删除
void delete(HashTable *table, char *key) {
    int index = hash(key);
    Node *current = table->buckets[index];
    Node *prev = NULL;
    while (current != NULL) {
        if (strcmp(current->key, key) == 0) {
            if (prev == NULL) {
                table->buckets[index] = current->next;
            } else {
                prev->next = current->next;
            }
            free(current);
            return;
        }
        prev = current;
        current = current->next;
    }
}

// 打印哈希表
void printTable(HashTable *table) {
    for (int i = 0; i < TABLE_SIZE; i++) {
        if (table->buckets[i] != NULL) {
            printf("桶%d: ", i);
            Node *current = table->buckets[i];
            while (current != NULL) {
                printf("(%s:%d) ", current->key, current->value);
                current = current->next;
            }
            printf("\n");
        }
    }
}
```

### 3. 哈希冲突处理方法总结

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 链地址法 | 同一位置用链表存 | 简单，无聚集 | 需要额外指针空间 |
| 线性探测法 | 冲突时往后找空位 | 空间利用率高 | 容易产生聚集 |
| 二次探测法 | 冲突时按平方步长找 | 缓解聚集 | 可能找不到空位 |
| 再哈希法 | 用另一个哈希函数 | 分布均匀 | 多一次哈希计算 |

### 4. 哈希表的使用场景

- 快速查找（字典、缓存）
- 去重（Set 底层）
- 计数（词频统计）
- 索引（数据库索引的一种结构）

### 5. 开放定址法实现

**概念：** 开放定址法在冲突时，在哈希表内部寻找下一个空位。所有元素都直接存在数组中，不需要额外链表。

**线性探测：** 冲突时依次向后探测 `(index + 1) % TABLE_SIZE`，找到空位存放。
- **优点：** 空间利用率高，实现简单
- **缺点：** 容易产生"聚集"，冲突多的区域探测长度变长

```c
#define TABLE_SIZE 10
int table[TABLE_SIZE];      // 数组实现哈希表
int empty[TABLE_SIZE];      // 标记该位置是否为空

// 线性探测插入
void insertLinear(int key) {
    int index = key % TABLE_SIZE;
    while (empty[index] == 1) {         // 有冲突，向后找空位
        index = (index + 1) % TABLE_SIZE;
    }
    table[index] = key;
    empty[index] = 1;
}

// 线性探测查找
int searchLinear(int key) {
    int index = key % TABLE_SIZE;
    while (empty[index] != 0) {
        if (table[index] == key) return index;  // 找到
        index = (index + 1) % TABLE_SIZE;
    }
    return -1;                          // 未找到（遇到空位）
}
```

**二次探测：** 冲突时按 `index + 1², index + 2², index + 3²...` 探测，缓解聚集现象。

**链地址法 vs 开放定址法：**

| 对比 | 链地址法 | 开放定址法 |
|------|---------|-----------|
| 存储 | 链表 | 数组 |
| 空间 | 需额外指针 | 全在表内 |
| 删除 | 简单 | 复杂（需标记删除，避免破坏探测链） |
| 聚集 | 无 | 线性探测有聚集 |
| 负载因子 | 可 >1 | 必须 <1 |

## 08 · 递归

### 1. 递归的基本概念

**概念：** 递归是指函数直接或间接调用自身的编程方法。递归包含两个要素：
1. **基线条件：** 递归终止的条件（不再调用自身）
2. **递归步骤：** 将问题分解为规模更小的同类问题

- **本质：** 递归调用栈 — 每次调用在栈上开辟新帧，返回时回收
- **适用场景：** 树形结构遍历、分治算法、数学定义（阶乘、斐波那契）

### 2. 递归求阶乘

```c
int fac(int n) {
    if (n == 0 || n == 1) {
        return 1;           // 基线条件
    } else {
        return n * fac(n - 1);  // 递归步骤：n! = n * (n-1)!
    }
}
```

### 3. 递归求幂函数

```c
int re(int k, int n) {
    if (n == 0) return 1;       // k^0 = 1
    if (n == 1) return k;       // k^1 = k
    return k * re(k, n - 1);    // k^n = k * k^(n-1)
}
```

### 4. 递归 vs 迭代

| 对比 | 递归 | 迭代 |
|------|------|------|
| 代码可读性 | 简洁（适合分治问题） | 相对复杂 |
| 空间复杂度 | O(n)（调用栈） | O(1) |
| 性能 | 有函数调用开销 | 更快 |
| 适用 | 树、图、分治 | 线性遍历 |

### 5. 汉诺塔（Hanoi）

**概念：** 把 n 个盘子从 A 柱借助 B 柱移到 C 柱，每次只能移动一个盘子，且大盘不能压小盘。是经典的递归分解问题。

- **分解：** 先把上面 n-1 个盘子从 A 移到 B（借助 C），再把最大盘从 A 移到 C，最后把 n-1 个盘子从 B 移到 C（借助 A）
- **移动次数：** 2^n − 1 次
- **递推公式：** T(n) = 2T(n−1) + 1，T(1) = 1

```c
void hanoi(int n, char A, char B, char C) {
    if (n == 1) {
        printf("%c -> %c\n", A, C);     // 基线：直接移动
    } else {
        hanoi(n - 1, A, C, B);          // 1. n-1 个 A→B（借助 C）
        printf("%c -> %c\n", A, C);     // 2. 最大盘 A→C
        hanoi(n - 1, B, A, C);          // 3. n-1 个 B→C（借助 A）
    }
}
```

### 6. 斐波那契数列（递归 vs 迭代）

```c
// 递归（指数级，存在大量重复计算）
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);     // 重复计算很多
}

// 迭代（O(n)，用变量保存前两项）
int fib_iter(int n) {
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int t = a + b;
        a = b;
        b = t;
    }
    return n <= 1 ? n : b;
}
```

**教训：** 朴素的递归实现可能有大量重复计算（指数级），可用记忆化（备忘录）或迭代优化。

## 09 · 查找（Search）

### 1. 顺序查找（线性查找）

**概念：** 从头到尾依次比较，直到找到或遍历结束。适用于无序表。

- **时间复杂度：** O(n)
- **优点：** 简单，对数据无要求
- **缺点：** 效率低

```c
int SeqSearch(int a[], int n, int key) {
    for (int i = 0; i < n; i++) {
        if (a[i] == key) return i;      // 找到返回下标
    }
    return -1;                          // 未找到
}
```

### 2. 折半查找（二分查找）

**概念：** 在有序表中，每次与中间元素比较，根据大小把查找范围缩小一半。

- **前提：** 数据必须有序（通常是递增）
- **时间复杂度：** O(log n)
- **查找判定树：** 折半查找的过程可以画成一棵二叉树

```c
// 迭代实现
int BinarySearch(int a[], int n, int key) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;   // 防溢出
        if (a[mid] == key) return mid;
        else if (a[mid] < key) low = mid + 1;
        else high = mid - 1;
    }
    return -1;                              // 未找到
}

// 递归实现
int BinarySearchRec(int a[], int low, int high, int key) {
    if (low > high) return -1;
    int mid = low + (high - low) / 2;
    if (a[mid] == key) return mid;
    else if (a[mid] < key) return BinarySearchRec(a, mid + 1, high, key);
    else return BinarySearchRec(a, low, mid - 1, key);
}
```

### 3. 查找算法对比

| 查找 | 前提 | 平均时间 | 最坏时间 | 数据结构 |
|------|------|---------|---------|---------|
| 顺序查找 | 无 | O(n) | O(n) | 顺序表/链表 |
| 折半查找 | 有序 | O(log n) | O(log n) | 顺序表（随机访问） |
| 二叉搜索树 | 二叉排序 | O(log n) | O(n) | 二叉树 |
| 平衡二叉树 | 平衡 | O(log n) | O(log n) | AVL 树 |
| 哈希查找 | 哈希函数 | O(1) | O(n) | 哈希表 |

**选择建议：**
- 数据量小 → 顺序查找
- 数据有序且固定 → 折半查找
- 频繁增删 → 二叉搜索树/平衡树
- 追求极致查找速度 → 哈希表
